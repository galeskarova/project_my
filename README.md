## Примеры использования
### Маскировка карты или счета
```print(mask_account_card("Visa Platinum 1234567890123456"))```
Вывод: Visa Platinum 1234 56** **** 3456

```print(mask_account_card("Счет 12345678901234567890"))```
Вывод: Счет **7890

### Преобразование даты
```print(get_date("2024-03-11T12:30:45.123456"))```

### Фильтрация операций по статусу

```operations = [
    {"id": 1, "state": "EXECUTED", "date": "2024-01-01T10:00:00"},
    {"id": 2, "state": "CANCELED", "date": "2024-01-02T11:00:00"},
    {"id": 3, "state": "EXECUTED", "date": "2024-01-03T12:00:00"}
]

executed = filter_by_state(operations)               
canceled = filter_by_state(operations, "CANCELED")
print(executed)  # [{'id': 1, ...}, {'id': 3, ...}]
```
### Сортировка по дате

```sorted_operations = sort_by_date(operations, reverse=True)``` 
```print(sorted_operations)```

## Документация и ссылки
Описание функций
get_mask_card_number(card_number: str) -> str
Принимает номер карты (строкой или числом) и возвращает маску в формате XXXX XX** **** XXXX.

get_mask_account(account: str) -> str
Принимает номер счета, возвращает маску вида **XXXX (только последние 4 цифры).

mask_account_card(account_card: str) -> str
Анализирует строку, содержащую тип и номер карты/счета. Если строка начинается с "Счет", применяет маскировку счета, иначе — карты. Возвращает строку с замаскированным номером.

get_date(date: str) -> str
Преобразует строку с датой в формате "%Y-%m-%dT%H:%M:%S.%f" в формат "ДД.ММ.ГГГГ".

filter_by_state(list_of_dicts: list, state: str = 'EXECUTED') -> list
Фильтрует список словарей, оставляя только те, у которых значение ключа 'state' равно заданному. По умолчанию state='EXECUTED'.

sort_by_date(list_of_dicts: list, reverse: bool = True) -> list
Сортирует список словарей по ключу 'date'. Параметр reverse=True (по умолчанию) означает сортировку по убыванию (сначала новые даты), False — по возрастанию.

filter_by_currency(transactions, currency_code)
Принимает список словарей с транзакциями и код валюты (например, "USD"). Возвращает генератор, который поочередно выдаёт транзакции, у которых в поле operationAmount.currency.code указан заданный код.

transaction_descriptions(transactions)
Принимает список транзакций и возвращает генератор, выдающий описание каждой операции (значение ключа description). Если ключ отсутствует или равен None, возвращается пустая строка.

card_number_generator(start, end)
Генерирует номера банковских карт в формате XXXX XXXX XXXX XXXX для целых чисел от start до end включительно. Диапазон допустимых значений – от 0000 0000 0000 0001 до 9999 9999 9999 9999 (т.е. численно от 1 до 9 999 999 999 999 999).

Модуль decorators.py содержит декоратор log, который автоматически логирует выполнение функции.

## Тестирование 
Проект покрыт автоматическими тестами с использованием фреймворка pytest. Тесты расположены в директории tests/ и охватывают все основные модули:

- tests_masks.py – тестирование функций маскировки номеров карт и счетов (get_mask_card_number, get_mask_account).

- tests_widget.py – тестирование функции mask_account_card (распознавание типа и корректное применение маскировки).

- tests_processing.py – тестирование функций фильтрации (filter_by_state) и сортировки (sort_by_date).

- test_generators.py - тесты для filter_by_currency, transaction_descriptions, card_number_generator

-tests/test_decorators.py – тесты для декоратора log

### Запуск тестов
```pytest tests/ -v```

Для получения отчёта о покрытии кода используется плагин pytest-cov:

```pytest tests/ --cov=src --cov-report=term```

### Покрытие кода
На данный момент тесты покрывают 90% кода модулей проекта. Основное внимание уделено:
- позитивным и негативным сценариям маскировки (различные форматы номеров, граничные длины, обработка None и пустых строк);
- корректному распознаванию «Счет»/«Карта» в функции mask_account_card (в том числе регистронезависимо);
- сортировке списка операций по дате (по возрастанию/убыванию) и устойчивости при одинаковых датах;
- фильтрации операций по статусу (в том числе при отсутствии ключа state или несовпадении фильтра);
